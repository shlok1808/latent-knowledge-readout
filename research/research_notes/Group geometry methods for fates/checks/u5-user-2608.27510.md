## 3. Errors (reading says / paper says / quote + page)
No outright factual errors in numbers or quotes. Four wording or mapping problems:

1. **Figure 10 depth-matching taken as a finding.**
   - Reading (bears_on_group_angle): "its finding that overlap is non-trivial only at matched depth says to compare pressures (H1) at matched relative depth."
   - Paper (p22): "Layer alignment is therefore a prerequisite for cross-concept sharing, reflecting that features at different depths encode qualitatively different representations."
   - Problem: a graph rooted at layer L contains only nodes at layers <= L, so Jaccard between a layer-2 graph and a layer-20 graph is capped by |small|/|large|. Low off-diagonal overlap is largely built in. The reading applied exactly this caveat to Figure 6 ("high J expected from construction") but not to Figure 10. Fix: add the same caveat; keep "match depth" as a design rule for us, but not as evidence from this paper.
2. **Figure 10 late block range.**
   - Reading takeaway: "late block about 12-24".
   - Paper (p22 text and the white box in the figure): late layers "L_T, L_R >~ 16". The reading's own text_matches_figure note (elevated region extends to about 12-15) is fine; only the takeaway line should say 16-25 per the paper's box.
3. **"Erased (6)" mapping.**
   - Reading (methods[1]): a near-empty probe graph (Llama Truthfulness L1, about 11 nodes) "means nothing builds the direction", offered as an erasure signature.
   - Problem: at L1 the graph can only contain nodes from layers 0-1, so a tiny graph is expected from depth alone, and the probe there is 55.2% (near chance). That is "never present", not "erased" (present, then removed). Fix: drop it as an erasure example, or label it "never built / too shallow".

## 4. Omissions (ordered by how much they matter)

**A. Flip rates do not fit the stated n = 50 (high).** The reading records "causal dissociation uses 50 prompts per concept" (p26, correct). With n = 50, every flip rate must be a multiple of 2%. Several reported values are not: 25.0% (Gemma Truthfulness probe-exclusive, p4/p19; Llama Sentiment shared, p24), 67.0% (Gemma Truthfulness shared, p4/p19), 17.0% (Gemma Reasoning shared p19; Llama Truthfulness shared p4/p24). The two numbers the paper uses to argue "partial routing of truthfulness" (25% and 67%) are exactly among the impossible ones. Likely cause: prompts were filtered ("all prompts pass the strong IID threshold", p24), so the effective n is smaller and differs by cell, and 25/17/67/58 look like k/12 or k/24. The reading missed this and also does not mention that (i) the ablation prompt-selection rule is undescribed, (ii) the Llama sentiment ablation prompts are all negative-class (Table 7 caption) while Gemma's are positive-class, and (iii) no table reports any CI, SD or per-prompt spread for delta S or flip rate. Add: "effective n unknown, possibly about 12-24 per cell; no uncertainty reported".

**B. Probe graph and logit graph overlap heavily, which the paper's own summary hides (high).** From the N columns (Table 4, p19): shared nodes are 47% (Toxicity), 46% (Sentiment), 60% (Reasoning), 53% (Truthfulness) of each probe graph (Llama, Table 7: 41%, 40%, 64%, 52%). Yet the Discussion says the features are "largely non-overlapping" and the Conclusion says "causally non-overlapping circuits" (both p8). Ablating the shared set flips 38% / 30% / 17% / 67% of tokens (Gemma) and 78% / 25% / 58% / 17% (Llama). The reading treats shared-node dependence as a Truthfulness exception only. It is present in every concept in both models.

**C. The double dissociation is partly built in by how the subsets are defined (high).** Exclusive sets come from graphs pruned to the features explaining 80% of the effect (A.4, p17). Nodes outside the logit graph have, by selection, little attributed effect on the logit; nodes outside the probe graph have little attributed effect on S. So "probe-exclusive ablation: 0% flips; logit-exclusive: delta S about 0" mostly confirms that the attribution approximation holds. The reading has the layer-position version of this (logit nodes above Lb cannot change S at Lb) but not the pruning version. Related: the only behaviour measure is the top-1 flip (Section 3.3, p4). There is no logit difference, probability change or KL, so "0% flips" does not show that the probe circuit is behaviourally inert. For our bypass fate we need a continuous answer-margin effect.

**D. Concept ordering does not replicate (high, drives project relevance).** The reading's relevance_to_project says truthfulness is the exception and "factual correctness information is less likely to be cleanly bypassed than toxicity or sentiment... a useful prior for our fate-split bet". In Gemma, shared-ablation flips are 67% (truthfulness) vs 38% (toxicity). In Llama, toxicity is 78% and truthfulness 17%, and the Llama truthfulness cell is uninformative (L1, 55%, about 11 nodes). So the ordering is one model, about 2B, unknown n, no CI. Also the truthfulness "anchor" features are lexical (city names, French text; Figure 11 and Appendix C), so partial routing may reflect shared lexical or topic features, not routing of a truth signal. The probe is trained on true/false statements, not on answer correctness under pressure. Fix: downgrade to "weak, unreplicated hint; do not use it to set the bet".

**E. Relative-depth consistency was not extracted (medium).** The checker brief asks for relative depth stable across models. From Table 3: belief layer as a fraction of depth is Toxicity 22/26 = 0.85 (Gemma) vs 14/16 = 0.88 (Llama), Sentiment 0.81 vs 0.94, Reasoning 0.58 vs 0.56, Truthfulness 0.54 vs 0.06 (Llama probe near chance). The reading gives Gemma layers only. Add the fractions with the caveat that Lb comes from the steepest-rise heuristic and Llama sentiment/truthfulness probes are weak (63%, 55%). Also note that Llama Lb = L1 for truthfulness arises because that score curve falls monotonically (Figure 7 right), so "steepest rise" is an arbitrary early layer.

**F. Which direction is the attribution target? (medium).** p3 says concept directions are Gram-Schmidt orthogonalised (order not stated; the last concept loses overlap with earlier ones, order-dependent). A.2 (p15) says the raw difference-in-means direction W_c is "used for CTA attribution throughout" and the LDA direction is for accuracy only. These are in tension. The reading states both without flagging it. Add as an ambiguity.

**G. Smaller overclaims in the paper the reading did not list (low).**
- "Probe-free indicator" and "without labeled supervision" (p8): the graphs are rooted at a label-trained probe direction and the regression target is probe validation accuracy, so neither is label-free.
- The Llama structural predictor's late-layer holdout is driven by n_embed_nodes (p25), a graph-size count. That weakens the "topology" reading.
- Local feature predictor uses n = p = 100 (A.5.2, p17), with top features chosen per prompt.
- Belief-point score is a projection onto a different unit direction at each layer, so it is confounded with residual-norm growth with depth (the plot is normalised, not norm-corrected).
- Sentiment's top feature (87 of 100 prompts) fires equally on both polarities (p6): it is a domain detector.

**H. Label the audit idea as ours (low).** actionable_fix suggests "if probe and logit circuits share few nodes on flipped items, the signal is not reaching the decision". That is the reading's extrapolation, not the paper's. Given point B (about half the nodes are shared in every concept), it needs a calibration baseline (overlap on resisted items) before it can mean anything. Mark it "our idea, uncalibrated".
