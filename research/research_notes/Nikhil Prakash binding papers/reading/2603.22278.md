# 2603.22278v3: The Dual Mechanisms of Spatial Variable Binding in VLMs

Cui, Prakash, Messica, Raina, Bau, Torralba, Rott Shaham (MIT / Northeastern). v3, 6 Oct 2026. 66 pages.
Read: main text in full. Appendix: A.4 (amplification setup, held-out alpha), C.7.1 Table 11, Table 5, C.7.5 Table 15. Figure page p07 checked.

## Simple
- Task: "the color of the square to the left of the green square is ___". Same for shapes, objects, What'sUp photos, and COCO-spatial.
- Models: Qwen2-VL-2B/7B, Qwen3-VL-8B, Gemma-3-4b, Pixtral-12B (all small; main text uses Qwen2-VL-7B).
- Two sources of "which position" (ordering) info:
  - Vision encoder: the main source. Its ordering signal is spread over background tokens in vertical/horizontal strips, not only on the object tokens. Linked to the encoder's positional encoding (App. C.6.2).
  - LM backbone: a backup. It builds its own ordering info on object tokens in middle layers (about 11-20), mostly visible when the vision signal is ablated.
- Method chain: last-token patching (layers 20-22 carry order, 23+ carry the answer) -> linear probe on object tokens -> probe also lights up background strips -> patching squares only does not reliably flip; squares + strips does (Figs 6-7, p7) -> ablate vision order, model drops but stays above chance -> add probe directions to all image tokens on COCO.
- COCO fix (Table 1 / Table 11, failures corrected), ordering probe vs random direction:
  - Per-item best alpha (an oracle upper bound): Gemma-3-4b 40.2% vs 9.6%; Qwen2-VL-2B 54.5% vs 13.1%.
  - One fixed alpha for all items: Gemma 26.8% vs 7.7%; Qwen2-VL-2B 42.6% vs 13.1%.
  - Held-out alpha (Table 5): probe 22-58%, random 0-19%.
  - Breaks at alpha=6, full re-evaluation (Table 15): Qwen2-VL-2B fixes 36.9%, breaks 6.4%. Gemma fixes 22.6%, breaks 18.5%.
  - Big models are near ceiling: Qwen2-VL-7B has 11 failures and fixes 3; Qwen3-VL-8B has 6 failures and fixes 4.

## Helps us
- Takeaway (a) mostly holds. The probe was trained on object tokens and then fired on background tokens. Squares-only patching did not reliably flip the answer; squares + strips did. Design rule for us: probe and patch over a set of positions (the answer token, the model's earlier turn, the user's pushback span, the final token), not only the answer position. Report position-set patching next to single-position patching. This supports the readout-failure vs not-routed split and the copy-vs-correctness control (a "Canberra" signal sitting on the earlier-turn tokens may be copy info, not correctness).
- One limit on (a): their background signal is mostly encoder positional structure (where something is), not content smeared around. In a text LLM the analogue is weaker. Treat "spread beyond the answer token" as a hypothesis to test, not a given.
- Takeaway (b) partly holds. The template (probe -> causal patch -> add probe direction vs random directions -> count fixed failures) fits Stage A injection and the not-routed fate. But 40-55% vs 10-13% (really 40.2/54.5 vs 9.6/13.1) is the per-item oracle alpha. The honest fixed-alpha numbers are 26.8/42.6 vs 7.7/13.1. For us: choose alpha on a validation split, report held-out fix rate, and report the break rate on items the model already got right (Gemma breaks 18.5%).
- Random-direction control: copy it, but match the norm and use many random draws. They used one random baseline per setting. Our "push both ways vs matched random directions" is stricter; keep it.
- Their fix adds the direction everywhere with no item info at test time. That is a cheap Stage B baseline ("global add of the probe direction") to compare against the fate-matched fix and DPO.
- H3 link (weak): their probes were trained only on correct items and still helped failures. So failures shared the same code. For us, a probe trained on normal items that does NOT help some failures would point to the transformed or bypass fates. That is H3's prediction, so log the fix rate per fate.

## Caveats
- Small VLMs (2B-12B) and a perception task, not factual recall under social pressure. The bigger models have almost no failures, so the fix numbers come from 2B-4B models.
- "Patching fixes it" is not the same as "the model naturally uses it". Adding the direction is causal control. The only endogenous-use evidence is the vision-ablation drop (Table 6) plus patching, and only in synthetic settings.
- Fix rates count only on failures and assume correct items stay correct. Only Table 15 checks breaks, and only at alpha=6 for two models.
